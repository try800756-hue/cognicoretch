# Contributing to CogniCoreTech

Thank you for your interest in contributing to **CogniCoreTech**. We build high-performance, privacy-first enterprise solutions adhering to strict zero-trust principles, secure memory management, and modern SDK security standards.

## Engineering & Security Standards
* **Language & Tone:** All documentation and code comments must be written in UK English.
* **Environment:** Development workflows are optimized for Arch Linux using FOSS terminal tools.
* **Code Quality:** Submissions must feature clean, production-ready code with complete error handling. We do not accept generic or copycat implementations.
* **Security First:** Zero hardcoded credentials, strict input validation via Pydantic, and explicit CORS and access policies.

## Contribution Workflow
1. Fork the repository and create your feature branch (`git checkout -b feature/amazing-feature`).
2. Commit your changes following conventional commit standards (`git commit -m "feat: add amazing feature"`).
3. Push to your branch (`git push origin feature/amazing-feature`).
4. Open a Pull Request detailing your architectural changes, risk analysis, and concrete testing validation.

## Good First Issues
Look for issues labeled `good-first-issue` on our GitHub repository to get started with small bug fixes or documentation improvements.
